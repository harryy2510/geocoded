# currency-code-formatters

Framework-agnostic ISO 4217 currency labels and filters.

## Install

```bash
bun add currency-code-formatters
```

## Source

TypeScript-first. Import from the package root. Types ship from `src/index.ts`.

Run `bun run build:packages` to emit declaration files into `dist/` before publishing.

See `packages/README.md` and `packages/PUBLISH.md`.
